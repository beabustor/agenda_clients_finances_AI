Configura tu oficina privada

1. En GitHub, crea una copia con Use this template → Create a new repository → Private. Si no aparece, el administrador debe activar «Template repository» en Settings. También puedes copiar el código a un repositorio nuevo privado.

2. Ejecuta la aplicación desde esa copia. No introduzcas datos reales en la plantilla pública o un equipo compartido. Los datos se guardan localmente, no se suben a GitHub.
