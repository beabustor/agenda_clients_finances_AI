# Logotipos de productos

Vectores de Simple Icons v11.15.0 (CC0); marcas de sus respectivos titulares. No son archivos descargados del centro oficial de cada marca. Su presencia identifica servicios y formatos, no implica afiliación, aprobación ni integración activa. Los iconos se muestran en el color indicado por Simple Icons.

| Google Drive | https://developers.google.com/drive/web/branding |
| WhatsApp | https://about.meta.com/brand/resources/whatsapp/whatsapp-brand |
| Microsoft Excel | https://developer.microsoft.com/en-us/fluentui#/styles/web/colors/products |

| Google Calendar | https://fonts.gstatic.com/s/i/productlogos/calendar_2020q4/v8/192px.svg |
| Google Sheets | https://sheets.google.com |

Access se incluye como alternativa comparada, no como componente del proyecto. Excel representa exportaciones previstas; las integraciones siguen sujetas al estado indicado en el README.
